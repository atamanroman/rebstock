# 2026-03-30

## Session 1

- Major schema redesign implementing all 6 requested changes:
  1. All PKs changed from INTEGER AUTOINCREMENT to TEXT (ULID)
     - Created `src/rebstock/ulid.gleam` — Crockford Base32, 48-bit ms timestamp + 80-bit random
     - Erlang FFI in `src/rebstock_ffi.erl` for `os:system_time(millisecond)`
     - Added `gleam_crypto` dependency for `strong_random_bytes`
  2. Added `vintages` table: `(id TEXT PK, wine_id TEXT FK, year INT, UNIQUE(wine_id, year))`
     - Replaces `vintages TEXT` column on wines (now derived via GROUP_CONCAT subquery)
     - Cellar stores `vintage_id TEXT FK` instead of `vintage INTEGER`
     - Ratings stores `vintage_id TEXT FK` instead of `vintage INTEGER`
     - Wishlist stores `vintage_id TEXT FK` instead of `vintage INTEGER`
     - `upsert_vintage()` and `vintages_for_wine()` added to db.gleam
  3. Added `users` table with `username TEXT PRIMARY KEY`
     - All user-scoped tables reference it via FK
     - `ensure_user()` called during import
  4. Country codes: wineries now store ISO 3166-1 alpha-2 codes
     - `country_to_iso()` mapping function in db.gleam
     - Covers all countries found in vivino data (FR, IT, ES, DE, etc.)
  5. Renamed `cellar.dated_at` → `cellar.date`
  6. Removed `wishlist.dated_at` column

- Router simplified: ID segments are now strings, no more `int.parse`
- Wine detail page uses `vintages_for_wine()` instead of splitting vintages string
- `upsert_wine` changed from RETURNING+ON CONFLICT to SELECT-then-INSERT/UPDATE pattern (needed because ULID PKs are generated client-side)
- All 23 tests pass, including new tests for country codes and ULID generation
- Deleted old `rebstock.db` (incompatible schema)
